# digital-preservation-ontologies
Digital Preservation and Archival Description Ontologies

Overview

This repository provides Excel datasets related to two ontologies used in digital preservation and archival description.

Datasets

1. PREMIS 3 Ontology

File: PREMIS_3_Ontology.xlsx

An Excel dataset containing information about the PREMIS 3 ontology. PREMIS supports the description of preservation metadata for digital objects.

2. Records in Contexts Ontology (RiC-O)

File: RiC-O_entities_relations.xlsx

An Excel dataset containing entities and relationships associated with the Records in Contexts Ontology (RiC-O), used in archival description.

Purpose

The datasets are shared for research, educational purposes, data analysis, and exploration of ontology classes and relationships.

Usage

Download the Excel files from this repository and open them using Microsoft Excel, LibreOffice Calc, or compatible spreadsheet software.
